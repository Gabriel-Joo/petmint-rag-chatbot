# 청크와 참조 그래프 요약 (원자료는 git 밖)

원자료는 git 밖이다. `data/chunks/`(파일 12개, 18,853,780바이트)와 `data/graph/`(파일 14개, 4,440,163바이트)이고, 크기는 2026-11-19 기준이다. 이 파일은 문서가 인용하는 숫자를 원자료에서 다시 뽑은 요약이다.

- 두 폴더는 `.gitignore` 8줄(`data/chunks/`)과 9줄(`data/graph/`)에 막혀 있다. 청크는 약관 원문을 쪼갠 것이라 올리지 않는다(2026-11-11 사용자 결정, `docs/README.md` 55줄). 문서가 숫자를 인용할 때는 원자료 대신 이 파일을 가리킨다.
- 2026-11-19에 원본 폴더에서 파일을 읽어 다시 셌다. 원문 글(약관 문장)은 옮기지 않았다. 수, 분포, 파일 이름, 크기, 파일 수정 시각만 적는다.
- 문서 줄 번호는 커밋 15f1f7a 판이다.

## 읽는 법

- **판**: 「기본」은 `data/chunks/*.json`, `data/graph/*.json`(01번, 03번 노트북이 2026-10-12에 만든 것)이다. v2, v3, v4는 `data/chunks_v2.py`가 다시 만든 판이고 운영 서빙은 v3다(14번 57, 58줄과 02번 5줄).
- **문서 값**과 **다시 센 값**이 같으면 **맞음** 칸이 「맞음」이다. 다르면 「다름」이고 까닭을 적는다.
- **센 방법**은 다시 셀 수 있게 쓴 정의다. 필드 이름은 청크 JSON의 키다.
