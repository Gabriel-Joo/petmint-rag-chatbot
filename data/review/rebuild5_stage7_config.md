# rebuild5 (7단계) 설정 — 2026-10-21 사용자 결정

이 파일이 7단계 설정의 원본이다. compact 뒤에도 이 파일을 먼저 읽는다.

| 항목 | 결정 |
|---|---|
| 청크 | **B** — v2 작은 조각으로 찾고(`PETMINT_SEARCH_VARIANT=v2`) 원래 청크를 보여줌(`PETMINT_DISPLAY_PARENT=1`). 학습 데이터 발췌도 같은 경로로 만든다 |
| 1차 후보 | **20** 유지(pool_k 늘리지 않음) |
| 질의 확장 | 켬(`PETMINT_SEARCH_EXPAND=1`) — 동의어 사전은 4번 결정대로 확장 후 회귀 확인 |
| QA 수정 | 반려동물 주어(pet_subject)는 **표시만**(빼지 않음). 계산이 틀린 QA(변호사비·인지액·의료비)는 **코드 값으로 고친다**(버리지 않음) |
| 일상어 | 질문 재작성에 **넣되**, 일상어 데이터를 **따로 학습하지 않는다**(같은 QA의 질문만 바꿈, 건수 늘리지 않음). 재작성 프롬프트에 예시 문장을 넣지 않는다(예시 따라 쓰기 → 반려동물이 소송·배당금 주어가 된 버그) |
| 목표 답 | **"결론 + 단서"** 형식 |
| 라벨 | 3가지(정답 있음 / 부분 / 정답 없음 → 거절). 정답 청크가 검색에 없을 때 넣는 비율과 '정답 없어 거절' 비율을 rebuild4(90.8% / 9.2%)와 비교해 기록 |
| 코드 답 | 의료비·한도·법률비용 카드 턴, 가정 등급·유형 질문, 미가입·연간 잔여는 코드가 답(6·7번) |
| 진행 | 학습 → 체크포인트 선택(data.ckpt_select) → GGUF·Ollama → **숨긴 세트(eval220_hidden) 열고** 평가(eval_serving --open-hidden, 3회 + judge, rebuild4 대비)까지 멈추지 않는다 |
| 서빙 최종 설정 | `PETMINT_SEARCH_EXPAND=1 PETMINT_CUSTOMER_FACTS=1 PETMINT_CHUNKS_DIR=data/chunks/v2 PETMINT_GRAPH_DIR=data/graph/v2 PETMINT_SEARCH_VARIANT=v2 PETMINT_DISPLAY_PARENT=1` |

바꾸지 않는 것: 생성 모델·임베딩·리랭커, 운영 클러스터 기본 동작(새 기능은 opt-in), 외부 API 0건.

## 2026-10-22 사용자 결정(흐름도의 미정 목록 1~10)
1. C 파일럿 100(되살린 incomplete 섞음)을 보고 전량
2. "발췌에 답 없음"은 거절 샘플로 쓰되 비율 상한 — 파일럿 비율을 보고 정한다
3. 정답 끼워넣기 하지 않는다(서빙과 모양이 달라진다) — finetune5의 insert 라벨은 쓰지 않는다
4. 동의어 사전 v2 — 측정 뒤 결정
5. v3 서빙 기본 — 평가 220 측정 뒤
6. 표 붙이기 사내규정에도 켠다(HR3)
7. rebuild5 채택 기준 — 미리 숫자로 정한다(제안: 채택 기준 절)
8. 체크포인트 선택 세트 → 평가 220 보이는 세트(옛 30문항은 좁다)
9. 운영 반영은 rebuild5 평가 뒤 한 번에
10. v2 청크·컬렉션은 남긴다(재현 근거)

## rebuild5 채택 기준 (2026-10-22 사용자 확정 — 바꾸지 않는다)

비교: rebuild4 대 rebuild5, 같은 서빙 설정(v3·확장·부모 표시·고객 사실·표), 평가 220 보이는 세트, 3회 평균.
rebuild4 기준값은 `logs/stage7/pre`(7pre) 측정 — 6·7번 코드 답으로 판정 대상 턴이 바뀌어 6단계 숫자(16.3 등)를 쓰지 않는다.

| # | 기준 | 선 | 근거 |
|---|---|---|---|
| 1 | 정답이 프롬프트에 있는데 거절 | 5건 이상 감소 | 학습으로 고칠 수 있는 몫 회당 11건(베이스가 같은 발췌로 정확)의 절반, 잡음 2σ 1.2 |
| 2 | 판정 정확 | +5 이상 | 잡음 2σ 3.0, rebuild3→4 핵심 유지 +9 |
| 3 | 판정 틀림 | +2 이하 | 비열등 한계 = 잡음 2σ 2.3 |
| 4 | 판정 예외누락 | +3 이하 | 잡음 2σ 2.8 |
| 5 | 답 없는 질문(N축) 거절 | 15/16 이상 | rebuild4 16/16 |
| 6 | 축별 판정 정확(S·P·C·M·L) | 어느 축도 −3 넘게 떨어지지 않음 | 한 축 희생 방지 |
| 7 | 숨긴 세트 44 | 정확 비율이 보이는 세트보다 10%p 넘게 낮지 않음 | 경보용(관문 아님) |

- 채택: 1~6 모두 만족
- 보류: 1 또는 2만 미달이고 3~6 통과 → 다른 체크포인트·C 비율 조정 후 한 번 더
- 불채택: 3 또는 5 위반
- 잡음 근거: stage 4~6 업무특화 6조건 × 3회의 회당 표준편차(정확 1.8 · 틀림 1.4 · 예외누락 1.7 · 거절 1.0 · 정답 있는데 거절 0.8)
