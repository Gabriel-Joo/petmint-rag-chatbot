## 2. 고치는 곳 — 표시만 (권장)

| 유형 | 고치는 방법 |
|---|---|
| 문장·낱말 중간 줄바꿈 | 줄을 잇는다. 띄울지 붙일지는 말뭉치 빈도(같은 약관에서 붙인 꼴 "동물병원"과 띄운 꼴 "동물 병원" 중 많은 쪽) → 같으면 뒤가 조사·어미면 붙임, 앞이 조사·어미면 띄움, 뒤가 따로 쓰이는 낱말이면 띄움. 항목 줄(①·1.·※··)과 박스·표는 새 줄 |
| 쪽 넘김 빈 줄 | 앞 줄이 문장 중간이고 뒤가 항목·박스·표가 아니면 지운다. 나머지 빈 줄 묶음은 하나로 |
| 등급 여러 벌 | 행의 coverage_type으로 나눠 등급 이름표를 단다. 근거 결과의 등급(가입 등급)을 먼저 펼치고 다른 등급은 접는다 |
| 항 구분 | 항이 둘 이상이면 행의 paragraph_num으로 "제1항·제2항" 작은 머리를 단다(①을 붙이면 호의 ①과 겹친다 — 시안에서 확인) |
| 같은 항의 행 | 분할 조각을 줄바꿈으로 잇고 나서 위를 적용한다(항목 하나가 두 행에 걸친다 — 일반조항 제4조 ②) |
| 【】 인용·정의 박스 | 왼쪽 띠·옅은 바탕의 상자, 제목 굵게. "예시"가 든 박스는 다른 색 |
| 공백 정렬 표 | 3칸 이상 공백으로 칸을 나눠 실제 표로(2줄 이상 연속일 때만) |
| 그림 글자 | 박스 뒤 들여 쓴 짧은 줄 묶음은 고정폭으로 모아 작게(흩어지지 않게) |
| 사설 글리프 | 지운다 |
| 접힌 미리보기(2줄) | 같은 줄 잇기를 적용한 글 |

- 어디서: 서버 `app/services/article_display.py`가 조항 원문 API 응답에 `blocks`(문단·항목·박스·표·등급 묶음)를 **더한다**(기존 `content`는 그대로). 근거 목록(sources)에는 `snippet`(이은 글)을 더한다. 화면(SourcePanel)이 blocks를 그린다
- 검색·발췌·프롬프트·학습 데이터는 바뀌지 않는다 — 응답의 새 칸만 쓰고 원문·청크·색인은 그대로다. 인사규정은 지금처럼(이미 깨끗하다)
- 비용: 이미지만(재색인 없음). 탐침·평가 220 프롬프트가 같아야 한다(중단 조건)

### 줄 잇기 정확도 — 재서 정했다

실제 약관 줄 2,494곳에 일부러 줄을 끊고(공백 자리 1,226 · 낱말 안 1,268, 정답을 아는 곳) 규칙을 맞혀 봤다. 그 줄 자신은 빈도에서 뺐다.

| 규칙 | 맞음 | 틀린 띄움("동물 병원") | 틀린 붙임("에게질병") |
|---|---|---|---|
| 조사·어미 규칙만 | 73.4% | | |
| kiwi 띄어쓰기(참고, 앱에 없는 의존성) | 79.6% | | |
| 빈도 → 조사 규칙 | 89.9% | 52 | 199 |
| **빈도 → 붙는 말·조사 → 뒤가 낱말이면 띄움(권장)** | **91.0%** | 102 | 123 |

남는 9%는 "빙 벽"·"의약 품"처럼 한 칸 틀린 띄어쓰기다 — 지금은 같은 자리가 모두 줄바꿈이다.

## 3. 전처리에서 고치면 (비용)

줄바꿈은 01 전처리(`notebooks/01_데이터_전처리.ipynb`의 PDF 텍스트 추출)에서 생겨 청크에 그대로 있다(v3 청크 1,065개 중 1,058개).
- 재색인: Milvus 약관 컬렉션 8개(기본·v2·v3·v4 × 강아지·고양이, 약 8,000행) + search-service 재시작 + 검색 회귀
- **프롬프트가 바뀐다**: 업무특화 발췌가 모두 달라진다. 운영 모델 rebuild4는 이 줄바꿈이 든 발췌로 학습했다(학습 샘플 300개 중 300개). 형식이 바뀌면 답이 흔들릴 수 있어 평가 220 3회·거절률·검색 회귀를 다시 재야 하고, 나쁘면 재학습까지 간다
- 그래서 지금은 표시만 고치고, 전처리 개선은 다음 재학습(rebuild5) 때 학습 데이터와 함께 하는 것이 맞다

## 5. 적용 (2026-10-28)

`app/services/article_display.py`(서버) + `web/src/components/ArticleText.tsx`(화면). 조항 원문 API에 `sections`, 근거 목록에 `snippet`을 더했다 — 원문 `content`는 그대로.

- 줄 잇기를 시안보다 하나 더 고쳤다: 실제 화면에서 "「동물 병원」"·"장해진단 서"가 틀렸다. 같은 문장이 등급마다 같은 자리에서 끊겨 낱말 빈도가 동률이었다 → 줄바꿈 양옆 한글 두 글자의 글자열 빈도("동물병원" vs "동물 병원")를 먼저 본다. 인공 줄바꿈 정확도 91.0% → 91.5%(부호 뗀 낱말) → **93.8%**(틀린 띄움 59 · 틀린 붙임 96). 남는 예: "빙 벽"(드문 낱말)
