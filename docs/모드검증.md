### 4. 공통

- [ ]  WebSocket 메시지 순서: 일반·사내규정은 sources → token → references → done (개발자 도구 Network → WS). calc는 오지 않는다
- [ ]  모드 전환: 일반 → 사내규정 → 일반 — 모드마다 세션이 따로이고, 돌아왔을 때 앞 대화가 남아 있다
- [ ]  새로고침 후 이전 턴 표시 — 질문·답변·출처 패널이 그대로(`GET /api/sessions/{id}`의 turns)
- [ ]  브라우저 콘솔 에러 없음(React key 경고 포함)

> `calc`(계산 카드)는 업무특화 모드에서 치료비가 든 질문에만 온다(sources → calc → token → references → done). 일반·사내규정에 calc가 오면 이상하다.
>
> 실패하면 `error` 메시지의 code로 원인을 가른다 — `search_unavailable`(search-service·hr_regulation), `llm_unavailable`(Ollama), `internal`(그 밖, 서버 로그).
