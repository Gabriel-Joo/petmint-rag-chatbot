# docs/

이 폴더에는 성격이 다른 두 종류의 문서가 있다. 섞지 않는다.

## 1. 설계 문서 — 노션 사본 (직접 고치지 않는다)

번호가 붙은 문서(`01_requirements.md`, `09_*.md` ~ `15_*.md`)는 노션에서 내보낸 사본이다. **원천은 노션이다.**

- 이 파일들을 저장소에서 직접 고치지 않는다.
- 설계가 바뀌어야 하면 무엇을 어떻게 바꿔야 하는지 **보고만 한다.** 노션에 반영한 뒤 다시 내보내 이 파일들을 덮어쓴다.
- 번호는 노션의 문서 체계를 따른다(예: 15 = 모니터링). 이 폴더에서 번호를 새로 매기지 않는다.

## 2. 작업 문서 — 저장소가 원천

노션에 없고 이 폴더에만 있는 문서다. 저장소에서 직접 고친다.

- 번호를 붙이지 않는다(설계 문서 번호 체계 밖).
- 측정·작업 계획·지시서처럼 진행 중인 작업을 위한 문서다.

| 파일 | 내용 |
|---|---|
| `next_rebuild.md` | 다음 FAQ·파인튜닝 재구축 지시서 |

측정 기록과 검수 결과는 `docs/`가 아니라 `data/review/`에 둔다.
